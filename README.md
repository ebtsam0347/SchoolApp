# The Spirit of Islam School — Staff Portal (HRMS)

*Thinking is our curriculum.*

Staff, attendance, leave and payroll portal for The Spirit of Islam School.
Forked from the FSHRMS codebase and rebranded (school crest, "Spirit" theme in
royal blue / gold, school name in the UI, PWA manifest and PDF reports).

- `frontend-main/` — React + Vite web app. Deploy guide: `frontend-main/CLOUDFLARE.md`
- `backend-main/` — Java/Spring microservices. Run guide: `backend-main/RUN.md`

Brand assets: `frontend-main/public/icons/school-logo.png` (crest),
`backend-main/services/payroll/src/main/resources/jasper/logo.png` (PDF letterhead).
